# 🌐 Networking Challenges

Projeto desenvolvido em **Java** com foco no aprendizado de conceitos fundamentais de redes de computadores utilizando a API de sockets e o protocolo HTTP.

Este repositório reúne desafios práticos que simulam a comunicação entre cliente e servidor, permitindo compreender como aplicações trocam informações pela rede.

---

# 📖 Sobre o projeto

O objetivo deste projeto é praticar programação de redes em Java por meio de desafios progressivos.

Durante os exercícios foram implementados exemplos utilizando sockets TCP e requisições HTTP, explorando conceitos importantes para o desenvolvimento de aplicações distribuídas.

---

# 🚀 Desafios implementados

## 📡 Challenge 01 - TCP Echo Server

Implementação de um servidor TCP capaz de receber mensagens enviadas por um cliente e devolvê-las exatamente como foram recebidas.

Conceitos praticados:

- TCP
- ServerSocket
- Socket
- Entrada e saída de dados
- Comunicação cliente-servidor

---

## 💻 Challenge 02 - TCP Client

Aplicação cliente responsável por conectar-se ao servidor TCP e enviar mensagens.

Conceitos praticados:

- Conexão TCP
- Socket
- Fluxo de dados
- Comunicação em rede

---

## 🔄 Challenge 02 v2 - TCP Client

Versão aprimorada do cliente TCP com melhorias na comunicação e organização do código.

---

## 🌍 Challenge 03 - HTTP GET

Aplicação que realiza requisições HTTP utilizando a classe **HttpClient** da biblioteca padrão do Java.

Conceitos praticados:

- HTTP GET
- HttpClient
- HttpRequest
- HttpResponse
- APIs REST

---

## 🖥️ Challenge 04 - HTTP Server

Desenvolvimento de um servidor HTTP simples utilizando Java.

Conceitos praticados:

- HTTP Server
- Tratamento de requisições
- Respostas HTTP
- Servidor local
